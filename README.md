# AgentSec

### Object-Oriented Explainable Security Agent Framework

AgentSec is a C++17-based project that explores the use of Object-Oriented Programming to build a simple autonomous security agent.

### Core Flow

**Observe → Analyze → Decide → Execute → Explain → Log**

### Technologies

* C++17
* Object-Oriented Programming
* Git & GitHub
